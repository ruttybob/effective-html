One card, every state it can reach.

The connector card is built once; each frame is the same markup carrying a state class. Chrome that survives a state — glyph size, card height, action row — sits at identical offsets in every frame, so vertical scanning shows only the state’s delta.

  • Connector brand color lives only inside the glyph. Atlas paper, night, lime, and red carry all state meaning.
  • The action row never disappears: settled states name their next step — Connect, Cancel, Pause, Disconnect, Reconnect, Retry, Request — and the loading skeleton reserves the slot.
  • Sync status is always mono, uppercase, and timestamped or counted.
  • Healthy is calm. Only pending, degraded, and loading states animate.
